# 右侧终端修复记录

2026-11-06，Apple Silicon macOS。针对用户提供的侧栏空白、会话进入中央标签、原智能体入口消失三张实测截图进行修复。第一版记录保留在 [历史交付](sidebar-terminal-2026-11-06.md)，不作为本次修复的验收证据。

## 使用方式

右侧活动栏新增独立的「终端」图标。点击 + 选择普通终端或已配置的 AI Agent，终端在右侧显示、输入和切换；中央继续显示 Cocos Web 编辑器。四宫格「智能体」恢复原有会话搜索功能，资源管理器、源代码控制和检查项入口保留。

已有配置不强制覆盖原来的侧栏选择；新配置默认右侧终端。上一版已经出现在中央的 Claude 等会话，可以在右侧 + 菜单的「移入已有终端」分组中选择，继续使用同一个进程。新建侧栏会话不会再出现在中央标签栏。会话位置及当前选择随配置保存，退出重开后恢复。

## 问题与修复

| 用户问题                      | 根因                                                                                              | 修复                                                                                                   |
| ----------------------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| 侧栏显示 No preview available | 第一版复用面向仪表盘的 AgentTerminalPreview，依赖已有中央终端渲染与连接，无法承担独立终端生命周期 | 侧栏使用原有完整 TerminalPane，通过 TerminalOverlaySlot 的内联挂载复用输入、启动、恢复、关闭和主机路由 |
| 终端进入中央标签、抢占编辑器  | activate:false 只是不立即切换选中项，仍创建中央标签；预览与中央终端之间存在依赖                   | 保存每个工作区的侧栏会话归属；中央标签和终端挂载过滤这些会话，侧栏选择不修改中央选中项                 |
| 四宫格原始功能消失            | 原 vault 入口被直接替换为终端                                                                     | 保留 vault 对应的 AiVaultSidebarPanel，新增独立 terminal 入口；历史按钮跳转到原有会话搜索              |

侧栏与中央仍共用同一套终端会话数据、PTY 和关闭保护；独立记录的是客户端展示位置。避免重复挂载同一终端，处理侧栏/中央输入焦点、工作区改名与移除、标签关闭清理和本地持久化。没有更换终端进程、增加聊天系统或修改 GitNexus 编辑器。

旧会话迁移直接列在 + 菜单的「移入已有终端」分组里，无需悬浮二级菜单；菜单沿用原有新建标签菜单的非模态方式。

## 边界

- 本地 arm64 包为 ad-hoc 签名，未公证、未发布。本轮未提交或推送；没有替换用户正在运行的挂载卷应用。
- Windows/Linux、真实 SSH/WSL 主机、移动端、另一台 Mac 的安装与原生窗口焦点交互未执行。客户端侧栏位置不随 WSL 工作区搬迁转移；目标端会话仍可从原终端入口使用并重新移入侧栏。
- 未执行相对 origin/main 的全历史分支门禁，也没有将当前版本的布局场景执行宣称为两个版本的完整布局对比。底层终端布局/拆分协议未改变。
- 不承诺 Rust 零卡顿或内存下降；相关效果尚需测量。
- a5-game-context 的实例预算、浏览器 Play 和 Cocos Web API 仍只交付独立设计文档，不包含对应运行时实现。
