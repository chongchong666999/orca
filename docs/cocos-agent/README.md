# Cocos Agent 工作台

2026-11-06。产品方向：中央 Cocos Web 编辑器负责场景/Prefab 和画面，右侧终端运行已有 AI CLI 或普通 Shell。项目与终端绑定到同一个工作区，后续通过统一 API 完成“修改 → 看到结果 → 验证 → 保存”。

**后续开发先读 [Claude / Codex 与可视化编辑的产品总方案](ai-cocos-product-plan.md)。**第一批聚焦同一服务、当前页面、图加数值、截图版本和受保护的修改/保存；然后完成参考图到 Prefab 的修改、绑定、自检与交付。下方 API 全表是长期参考。2026-11-07 增加免费固定签名、包体瘦身、浏览器 Play 和本地实例预算，见 [本轮实现记录](desktop-runtime-2026-11-07.md)。

## 本轮实现

右侧独立“终端”入口提供终端会话，点击 + 可选普通终端及当前主机已检测、已启用的 AI Agent；复用原有启动配置。普通终端、Agent 都是可交互的真实终端，不增加一套聊天产品。

- 新配置默认显示右侧终端，宽度 420；已有配置保留用户选择，点击终端图标即可进入。
- 会话按工作区显示。切换、关闭、收起再展开复用已有终端；关闭沿用固定标签/正在运行任务的保护。
- 新建侧栏会话保持中央浏览器/编辑器选中；侧栏会话不再出现在中央标签栏；通过“移入已有终端”可以把原来的会话移到侧栏。
- 四宫格“智能体”入口恢复原有会话历史搜索，终端面板中的历史按钮也可跳转。终端颜色和字体跟随应用终端设置。
- 第一批 AI 接入使用内置 `cocos-editor` MCP：新建 Claude/Codex 终端绑定当前编辑器页面，读取 Prefab、选择、图和数值，再修改、回看和受保护地保存。普通 Shell 保持原行为。接口和验收边界见 [M0 实现记录](m0-editor-context-2026-11-06.md)。

验证记录见 [侧栏终端修复](sidebar-terminal-fix-2026-11-06.md)；此前内置编辑器基线见 [原有验收记录](acceptance-2026-11-06.md)。

macOS 无证书内部分发与反复文件授权的根因、打包处理和验收边界见 [权限记录](macos-internal-distribution-2026-11-06.md)。

装好 cocos-agent 即可在任何终端、Claude Code 和 Codex 使用内置的 `a5-game-context` 与 `cocos-cli`，不再单独 npm 安装，版本跟随 cocos-agent。macOS 和 Windows 的做法、决策与 Windows 剩余阻塞见 [命令注册记录](a5-game-context-commands-2026-11-11.md)。
