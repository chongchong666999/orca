## 使用方式

右侧“智能体”图标进入终端面板，点击 + 选择“新终端”或当前主机的 AI Agent。上方会话标签可切换、关闭；历史按钮进入原有会话搜索。

新配置默认打开右侧终端，宽度 420。已有配置保留原来的侧栏选择和宽度。新建右侧终端保持中央 Cocos 编辑器/浏览器选中。会话与当前工作区绑定，普通文件夹同样可用；同一会话也保留在原有中央标签中，不重复创建进程。

第一期复用现有终端输入、主题、复制粘贴、主机路由及 Agent 启动配置。未增加独立聊天面板；不会因为终端在编辑器旁边，就自动让 AI 得到编辑器图像。观察接口见后续 API 设计。
